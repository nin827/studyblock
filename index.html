StudyBlock must be served over HTTP

Opening index.html directly from disk (file://) doesn't work: browsers block ES modules and fetch there.

In the project folder, run:

py -m http.server 8000 --bind 127.0.0.1

then open http://localhost:8000.

To use it without a server, build the single-file version with py tools/bundle.py and open dist/studyblock.html.
