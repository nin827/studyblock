# Tickets

Open questions and decisions for the user, one Markdown file each, so work isn't blocked waiting on answers.

- File name: `NNN-short-slug.md` (zero-padded, increasing).
- Each ticket: title, `Status: open | resolved`, date raised, the question, options (recommended first), and once answered a `## Resolution` section.
- When the user asks to "clear tickets", go through open ones, ask them, record the answer under `## Resolution`, set `Status: resolved`, and act on it.
