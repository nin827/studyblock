# Radioactivity

Practise the physics of unstable nuclei: reading nuclide notation, balancing alpha, beta and gamma decay equations, and working with half-life. Every nucleus is real, decay chains follow the real uranium and thorium series, and each half-life is stated in the question. This subject covers the physics only, not health effects or radiation doses.

Nuclides are written with the mass number on top and the atomic number below the symbol: `²³⁸₉₂U` is uranium-238, with A = 238 and Z = 92.

| Idea | Rule |
| --- | --- |
| Protons | Z (the bottom number) |
| Neutrons | A - Z |
| Alpha decay (⁴₂He) | A goes down by 4, Z goes down by 2 |
| Beta decay (⁰₋₁e, an electron) | A stays the same, Z goes up by 1 |
| Gamma (γ) | A and Z stay the same |
| Half-life | after n half-lives, (1/2)^n of the original is left |

| Level | What to expect |
| --- | --- |
| Easy | Counting particles, single decays, whole numbers of half-lives |
| Medium | Isotopes, two-step decays, fractions like `1/8`, background count correction |
| Hard | Longer decay chains, a time that isn't a whole number of half-lives; decimals rounded to 2 decimal places, some in several parts |

> [!TIP]
> Fractions are typed in simplest form, like `7/8`. Subtract the background count rate before you halve anything: background radiation doesn't decay with the sample. For a time that isn't a whole number of half-lives use `N = N0 × 0.5 ^ (t / T)`; the calculator has `log` for finding n.
