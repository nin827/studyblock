# Computing Terms

The everyday vocabulary of computing: the parts inside a computer, how networks connect them, how data is measured and how to keep it safe.

## Hardware

| Term | What it is |
| --- | --- |
| CPU | Central processing unit: runs program instructions |
| GPU | Graphics processing unit: many small cores for graphics and parallel work |
| RAM | Fast working memory. It is volatile, so its contents are lost without power |
| SSD / HDD | Long-term storage. An SSD uses flash chips; a hard disk drive has spinning platters |

## Networks

- A **LAN** covers a small area such as a home or office; a **WAN** spans a large area. The internet is the biggest WAN.
- A **router** forwards data between networks. **DNS** turns names like example.com into **IP addresses**.
- **HTTPS** is HTTP with encryption (TLS).

## Units of data

A **bit** is a single 0 or 1, and a **byte** is 8 bits. There are two sets of prefixes, and they are easy to mix up:

| SI (decimal) | Size | Binary (IEC) | Size |
| --- | --- | --- | --- |
| 1 KB (kilobyte) | 1000 bytes | 1 KiB (kibibyte) | 1024 bytes |
| 1 MB (megabyte) | 1000 KB | 1 MiB (mebibyte) | 1024 KiB |
| 1 GB (gigabyte) | 1000 MB | 1 GiB (gibibyte) | 1024 MiB |

This module uses the SI meaning, so 1 KB = 1000 bytes. Some software still writes "KB" when it means 1024 bytes, which is why the binary units were introduced.

Network speeds are usually given in **bits** per second (Mbps), and file sizes in **bytes** (MB). Divide by 8 to convert from bits to bytes.

## Security

- **Encryption** scrambles data so that only someone with the key can read it.
- **Phishing** tricks people into giving away passwords or other details.
- **Two-factor authentication (2FA)** asks for two different kinds of proof, for example a password plus a code from your phone.
- A **firewall** allows or blocks network traffic according to its rules.
