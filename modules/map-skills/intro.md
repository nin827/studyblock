# Map Skills

Read maps like a navigator: turn map centimetres into real kilometres, find places with grid references, follow bearings and work out the time on the other side of the world. Every question states the scale, grid layout or UTC offsets it uses.

| Topic | What you do |
| --- | --- |
| Scale & distance | Use a scale like 1 : 25 000 (1 cm on the map = 25 000 cm on the ground). Hard questions add areas and contour gradients written as 1 : n. |
| Grid references | Read a small grid given as a table. 4 figures name a 1 km square; 6 figures add tenths. Easting (along) comes first. |
| Bearings | Angles clockwise from north, with three figures: 045°, 270°. |
| Time zones | Fixed offsets such as UTC+9 or UTC−5, with no daylight saving. |

**Answer formats**

- **Numbers:** type the number; each question says how to round. 1 km = 100 000 cm.
- **Grid references:** type the digits with no spaces, like `3417` or `343176`.
- **Bearings:** type the degrees, with or without the leading zero (`045` or `45`).
- **Times:** 24-hour clock as `HH:MM` with two digits each, like `07:05`. Days are picked from a list.

> [!TIP]
> For time zones, always go through UTC: take away the first place's offset, then add the second place's.
