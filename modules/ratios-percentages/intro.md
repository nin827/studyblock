# Ratios and Percentages

Compare quantities: simplify and share ratios, scale with maps and similar shapes, work with direct and inverse proportion, and handle percentages, including reverse and successive changes. Some questions are multiple choice, with wrong options taken from common mistakes.

| Idea | How it works |
| --- | --- |
| Simplify a ratio | divide every part by the greatest common factor: `12:18 = 2:3` |
| Share in a ratio | total ÷ sum of the parts = one part, then multiply |
| Form `1:n` | divide both parts by the first part |
| Map scale `1:25000` | 1 cm on the map is 25 000 cm (250 m) in real life |
| Similar shapes | if lengths scale by k, areas scale by k² and volumes by k³ |
| Direct proportion | find the value for one, then scale up: `y = k × x` |
| Inverse proportion | the product stays the same: `y = k / x` |
| Percent of | `p / 100 × amount` |
| Percentage change | `(new - old) / old × 100` |
| Multiplier | +15% means × 1.15; -15% means × 0.85 |
| Reverse percentage | new value ÷ multiplier = original |
| Successive changes | multiply the multipliers, never add the percentages |

| Level | What to expect |
| --- | --- |
| Easy | Simplifying and sharing two-part ratios, unit rates, simple percentages; whole-number answers |
| Medium | Ratios with units or decimals, three-part sharing, map scales, percentage change and multipliers |
| Hard | Combining ratios, similar shapes, `y ∝ x²` and `y ∝ 1/x`, reverse, successive and repeated percentage changes |

**How to type answers.** Type ratios with a colon and no spaces, in simplest form, like `3:4` or `2:3:5`. Type percentages as plain numbers without the % sign, using a minus sign for a decrease. Round to 2 decimal places when the question asks (answers within 0.005 are accepted).
