> [!NOTE] Made-up statements, no opinions
> Every statement, option and candidate here is invented, and each question states its own rules. Nothing asks for a view on religion, politics or any real thinker: each answer is settled by checking every case, so there is exactly one right answer.

# Applied scenarios (Philosopher)

Scenario questions for the **Philosopher** role, from Medium to Expert+. Each one is a single made-up scenario with several linked answers, mostly counts and choices. The calculator is on, and the numbers from the prompt are already in it where that helps.

## Argument forms

Premises and a conclusion are written with letters standing for made-up statements. You name the form (modus ponens, modus tollens, affirming the consequent and so on), decide whether it is valid, and at higher levels count the true/false assignments that make every premise true or break the conclusion. Expert+ chains the steps into dilemmas and long chains.

## Truth tables

A compound statement built from not, and, or, if-then and if-and-only-if is worked row by row. You count the true rows, decide whether it is a tautology, a contradiction or neither, and compare two statements: are they equivalent, and does one entail the other?

## Decisions under risk

A payoff table gives each option's result in each state, with the state probabilities. You work out an expected value, pick the best option by expected value and by the maximin rule, and at Expert+ use regret and the value of perfect information.

## Ballots and voting

Members rank a few choices, and each row of the table says how many chose that order. You tally pairwise contests, find the Condorcet winner or decide there is none, and count Borda points, plurality winners and instant-runoff results. Different rules can pick different winners from the same ballots.
