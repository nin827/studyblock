# Statistics

Summarise data and reason about chance: averages, how spread out data is, probability, and weighted averages such as course grades. Data lists have at most 12 values. Some questions are multiple choice, with wrong options taken from common mistakes.

| Measure | How to find it |
| --- | --- |
| Mean | sum of the values ÷ how many there are |
| Median | sort the values; the middle one, or halfway between the two middle ones |
| Mode | the value that appears most often |
| Range | largest - smallest |
| Q1 / Q3 | median of the lower / upper half of the sorted data; for an odd count, leave the middle value out of both halves |
| IQR | Q3 - Q1 |
| `P(event)` | favourable outcomes ÷ all equally likely outcomes |
| `P(A and B)` | `P(A) × P(B)` for independent events |
| `P(at least one)` | `1 - P(none)` |
| Weighted average | `Σ(weight × value) / Σ(weight)` |

| Level | What to expect |
| --- | --- |
| Easy | Short sorted lists with whole-number answers, single-event probabilities as fractions |
| Medium | Unsorted lists, quartiles, two independent events, grades with percentage weights or credits |
| Hard | Longer lists with negative numbers, "at least one" probabilities, the exam score needed for a target grade |

**How to type answers.** Round to 2 decimal places when the answer is not a whole number (answers within 0.005 are accepted). Probabilities are asked either as a decimal, like `0.25`, or as a fraction in simplest form with no spaces, like `3/8`; the question says which.
