# Trigonometry

Use the ratios between sides and angles to find missing lengths and angles: exact values for special angles, SOH CAH TOA in right-angled triangles, and the sine and cosine rules for any triangle. Angles are always in degrees, and the quiz calculator's `sin`, `cos` and `tan` work in degrees too. Some questions are multiple choice, with wrong options taken from common mistakes (such as the wrong ratio, or a calculator left in radians).

| Formula | Meaning |
| --- | --- |
| `sin(θ) = opposite / hypotenuse` | **SOH** |
| `cos(θ) = adjacent / hypotenuse` | **CAH** |
| `tan(θ) = opposite / adjacent` | **TOA** |
| `θ = asin(…)`, `acos(…)`, `atan(…)` | inverse functions give the angle back |
| `a / sin(A) = b / sin(B) = c / sin(C)` | sine rule: side a is opposite angle A |
| `a² = b² + c² - 2bc × cos(A)` | cosine rule, for two sides and the angle between them |
| `cos(A) = (b² + c² - a²) / (2bc)` | cosine rule rearranged, for three sides |
| `Area = ½ × a × b × sin(C)` | area from two sides and the angle between them |

| Angle | 0° | 30° | 45° | 60° | 90° |
| --- | --- | --- | --- | --- | --- |
| sin | 0 | 1/2 | √2/2 | √3/2 | 1 |
| cos | 1 | √3/2 | √2/2 | 1/2 | 0 |
| tan | 0 | √3/3 | 1 | √3 | undefined |

| Level | What to expect |
| --- | --- |
| Easy | Exact values, one multiplication for a side, whole-number sides |
| Medium | Dividing by sin, cos or tan to find a side, decimal lengths, the sine rule, the cosine rule for a side, triangle area |
| Hard | Angles of elevation and depression, ladders and slopes, angles from the sine and cosine rules, two-step problems |

**How to type answers.** Lengths and angles are rounded to 2 decimal places (answers within 0.005 are accepted). Type angles as plain numbers without the ° sign. Keep full precision in your working: store each step in a calculator row (`_angle`, `_hyp`, …) instead of retyping rounded values. Exact values like √3/2 are always multiple choice; √2/2 is the same as 1/√2, and √3/3 the same as 1/√3.
