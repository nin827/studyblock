# Word Roots: how to solve

## General
- Split the word into prefix + root + suffix, then add the meanings: *re-* + *port* = carry back.
- Think of two or three words you know that share the part; what they have in common is its meaning.
- A prefix comes at the start of a word (*un*happy), a suffix at the end (care*less*).

## Latin roots
1. Find the root inside a familiar word, then guess the meaning from it (common roots in the table below).
2. For "which word contains…", look inside each option for the root, then check the meaning fits.

| Root | Meaning | Examples |
| --- | --- | --- |
| port | carry | transport, portable |
| dict | say | predict, dictionary |
| scrib / script | write | describe, postscript |
| spect | look | spectator, spectacles |
| aud | hear | audio, audience |
| rupt | break | erupt, interrupt |
| duc / duct | lead | conduct, educate |
| cred | believe | credit, creed |
| bene / mal | good / bad | benefit, malfunction |

Watch out: a matching spelling is not always the root: *port* in "portrait" has nothing to do with carrying, so check the meaning fits the whole word.

## Greek roots
1. Many science and tech words are Greek; split them into two roots (common ones in the table below).
2. Combine the meanings: *tele* + *vision* = seeing from far away.

| Root | Meaning | Examples |
| --- | --- | --- |
| bio | life | biography |
| graph | write, draw | autograph |
| phon | sound | headphones |
| geo | earth | geology |
| chron | time | chronicle |
| tele | far | television |
| micro | small | microscope |
| phil | love | philosophy |
| anthrop | human | anthropology |
| path | feeling, suffering | sympathy |

Watch out: *path* also gives "disease" words (pathology), but the root sense is feeling or suffering.

## Prefixes
1. Strip the prefix and see what's left: *re*-*write*, *mis*-*spell*.
2. Look the prefix up in your head (common ones in the table below).
3. Check by rebuilding: does "before + view" describe a preview? Yes.

| Prefix | Meaning |
| --- | --- |
| un-, in-, dis- | not |
| re- | again, back |
| pre- / post- | before / after |
| anti- | against |
| sub- | under |
| inter- | between |
| trans- | across |
| circum- | around |
| semi- | half |
| poly- / mono- | many / one |
| mis- | wrongly |

Watch out: *pre-* (before) and *post-* (after) are opposites and easy to swap under time pressure.

## Suffixes
1. A suffix often changes the word class: *-ness* makes a noun, *-ify* makes a verb, *-ful* and *-less* make adjectives.
2. Read the word as "base + suffix meaning": *care* + *less* = without care (common suffixes in the table below).

| Suffix | Meaning |
| --- | --- |
| -less / -ful | without / full of |
| -able | able to be |
| -er, -ist | a person who does it |
| -ology | the study of |
| -phobia | fear of |
| -cide | killing |
| -cracy | rule, government |
| -itis | inflammation |
| -ify | to make |

Watch out: *-ist* and *-er* both mean a person; *-ism* is the belief or practice, not the person.
