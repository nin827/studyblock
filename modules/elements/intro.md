# Chemical Elements

Get to know the periodic table: element symbols, atomic numbers and the families elements belong to. Names and symbols follow IUPAC, so you will see the IUPAC spellings caesium, aluminium and sulfur.

| Family | Group | Examples |
| --- | --- | --- |
| Alkali metals | 1 | Lithium (Li), sodium (Na), potassium (K) |
| Alkaline earth metals | 2 | Magnesium (Mg), calcium (Ca), strontium (Sr) |
| Transition metals | 3–12 | Iron (Fe), cobalt (Co), copper (Cu) |
| Halogens | 17 | Fluorine (F), chlorine (Cl), bromine (Br), iodine (I) |
| Noble gases | 18 | Helium (He), neon (Ne), argon (Ar), krypton (Kr) |

The **atomic number** is the number of protons in an atom's nucleus. Each element has its own.

| Level | What to expect |
| --- | --- |
| Easy | The lightest and most common elements |
| Medium | Symbols that come from Latin names, and heavier elements |
| Hard | Less familiar elements and trickier families |

**Tip:** typed answers ignore capital letters, so `fe` and `Fe` are both accepted for iron. Spelling still counts.
