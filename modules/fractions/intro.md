# Fractions

Work with fractions in your head: simplify them, add, subtract, multiply and divide them, and switch between fractions, decimals and percents. The calculator is turned off for this module, because the mental working is the point. Some questions are multiple choice. The wrong options come from common mistakes, so read carefully.

| Rule | Example |
| --- | --- |
| Simplify: divide top and bottom by their greatest common factor | `12/16 = 3/4` (divide by 4) |
| Add or subtract: use a common denominator first | `1/3 + 1/4 = 4/12 + 3/12 = 7/12` |
| Multiply: tops times tops, bottoms times bottoms | `2/3 × 3/5 = 6/15 = 2/5` |
| Divide: multiply by the reciprocal | `3/4 ÷ 1/2 = 3/4 × 2/1 = 3/2` |
| Mixed number to improper fraction | `2 1/3 = (2 × 3 + 1)/3 = 7/3` |
| Fraction to decimal | `3/8 = 3 ÷ 8 = 0.375` |
| Fraction to percent | `3/8 × 100 = 37.5%` |

| Level | What to expect |
| --- | --- |
| Easy | Small denominators, like denominators to add, exact decimals and percents |
| Medium | Different denominators, division, answers above 1 as improper fractions, rounding to 2 decimals |
| Hard | Negative fractions, mixed numbers, improper fractions to compare and convert |

**How to type answers.** Write fractions in simplest form with no spaces around the slash, like `3/4`. Use an improper fraction like `7/4` when asked, and put a minus sign in front for a negative answer: `-7/4`. When a question asks for a mixed number, type the whole number, a space, then the fraction: `2 1/3`. Percents are typed as plain numbers without the % sign. A fraction that is correct but not simplified, like `6/8`, is marked wrong.
