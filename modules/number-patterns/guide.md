# How to solve: Patterns & Sequences

## General

- Look for the simplest rule that fits **every** term shown, not just the first few.
- Check your rule on the last terms before you use it.

## Number sequences

1. Write the differences between neighbouring terms.
2. If they're all the same, add that difference again.
3. If not, write the differences of the differences. If those are the same, the differences grow steadily: continue them.
4. Still nothing? Try the other rules below.

Other rules to try:

- Divide each term by the one before (a constant ratio).
- Compare with the square numbers (1, 4, 9, 16, 25, …) or cube numbers (1, 8, 27, 64, …).
- Add the two terms before.
- Multiply by 2 or 3, then add or subtract a little.
- Look at every other term (two sequences taking turns).
- Check whether the steps alternate between adding and multiplying.

**Next two terms:** apply the rule to get the next term, then apply it again to that term.

**Missing term:** find the rule from a stretch with no gap, then fill the gap and check the rule still works across it.

**A far-off term:** when the differences grow by the same amount each time, term n = first term + the sum of the first n − 1 differences. Those differences form an arithmetic list, whose sum is (number of values) × (first + last) ÷ 2.

**First term over a limit:** keep extending the sequence and count the terms as you go.

## Letter patterns & codes

- Turn letters into numbers: A = 1, B = 2, …, Z = 26. Then treat it as a number sequence.
- When a pattern wraps, after Z comes A again (and before A comes Z).
- Pairs like AZ, BY, CX: the second letter is the first one's mirror (A↔Z, B↔Y, …): their places add up to 27.

**Codes:** line up the example word with its code and count how far each letter moves.

- Every letter moves the same distance: a shift code.
- The 1st letter moves 1, the 2nd moves 2, …: a growing shift.
- Each letter becomes its mirror (A↔Z): a mirror code.

To decode, apply the rule backwards.

## Shape patterns

- Find the block that repeats and how long it is.
- To find a far-off item, divide its position by the length of the repeat. The remainder is its place in the repeat; remainder 0 means the last item of the repeat.
- **Turning arrows:** each step turns by the same angle. 45° is an eighth of a turn and 90° a quarter.
- **Two cycles:** look at the shapes only, then at filled/hollow only. Each has its own repeat. Work out the shape and the filling separately.
- **Counting:** the whole pattern repeats after the lowest common multiple of the two lengths. Count inside one full repeat, multiply by the number of full repeats, and add the leftover part. For "how many filled", only the filled/hollow repeat matters.
