# Genetics

Work out what offspring to expect from a cross. Every question builds a fresh cross, so you practise the method, not memorised answers.

| Notation | Meaning |
| --- | --- |
| `T` / `t` | upper case = dominant allele, lower case = recessive |
| `Tt` | a genotype (two alleles, one from each parent) |
| `X^H` / `X^h` | alleles on the X chromosome; males are `X^H Y` or `X^h Y` |
| `I^A`, `I^B`, `i` | ABO blood group alleles (`I^A` and `I^B` are codominant) |
| p, q | dominant and recessive allele frequencies (Hardy–Weinberg) |

| Level | What to expect |
| --- | --- |
| Easy | Simple crosses, gametes, reading genotypes |
| Medium | Ratios, expected numbers, blood groups, allele frequencies |
| Hard | Working out parents' genotypes, probabilities, carrier frequencies, multi-part questions |

**Answer formats:** type percentages without the % sign (`25` for 25%), and fractions in simplest form like `2/3`. Each question says how to round. Ratios are picked from a list, in the order the question gives (for example tall : short).

Every question states its assumptions: complete dominance, independent assortment for two genes, and Hardy–Weinberg equilibrium for populations.
