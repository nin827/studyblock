# How to solve: Algebra

## General

- Whatever you do to one side of an equation, do to the other side too.
- Undo operations in reverse order: deal with adding or subtracting first, then multiplying.
- Check your answer by putting it back into the original equation.
- Hard linear answers may be fractions: give them to 2 decimal places (answers within 0.005 are accepted).

## Linear equations

1. Start with `ax + b = c`.
2. Move the constant: subtract `b` from both sides (or add it, if it is negative). You get `ax = c - b`.
3. Divide both sides by `a`.
4. Check: `a × x + b` should give `c`.

Example: `3x + 5 = 20` → `3x = 15` → `x = 5`. Check: 3 × 5 + 5 = 20.

**Watch out:** with a negative coefficient, `-4x = 12` gives `x = -3`. Keep the sign when you divide.

**Expert: fractions on both sides.** Multiply both sides by both denominators, expand, collect x on one side, then divide. Example: `(x + 1)/2 = (x + 4)/3` → `3(x + 1) = 2(x + 4)` → `3x + 3 = 2x + 8` → `x = 5`.

**Expert: simultaneous equations.** Clear any fractions first (multiply every term), then make one variable's coefficients match and subtract to eliminate it. Solve for the other variable and substitute back.

**Expert: inequalities.** Solve like an equation, but when you multiply or divide both sides by a **negative** number, reverse the sign: `-3x < 12` gives `x > -4`.

**Expert: word problems.** Name the unknown (n), write each cost as fee + rate × n, set the two costs equal and solve. Above the break-even point, the option with the lower rate is cheaper.

## Quadratic roots

1. Write the equation as `x² + px + q = 0`.
2. Find two numbers that **multiply to q** and **add to p**. Use the signs: if q is positive, both numbers have the sign of p; if q is negative, they have opposite signs.
3. Factor: if the numbers are m and n, then `(x + m)(x + n) = 0`.
4. Each bracket gives a root: `x = -m` or `x = -n`. Give the **larger** one.

Example: `x² - 5x + 6 = 0`. The numbers are -2 and -3 (product 6, sum -5), so `(x - 2)(x - 3) = 0`, the roots are 2 and 3, and the larger is 3.

**Watch out:** the roots have the opposite sign to the numbers in the brackets. `(x + 4)` gives `x = -4`.

**Expert: rearrange first.** Expand brackets and move every term to one side so it reads `ax² + bx + c = 0`. With a ≠ 1, find two numbers that multiply to a × c and add to b, split the middle term, and factor (or use the quadratic formula). A bracket like `(3x - 2)` gives the root x = 2/3 ≈ 0.67.

**Expert: completing the square.** For `x² + bx = d`, add (b/2)² to both sides; the left side becomes `(x + b/2)²`. So h = b/2 and k = d + h². Then x = -h ± √k. Example: `x² + 6x = 4` → `(x + 3)² = 13` → x = -3 ± √13, larger ≈ 0.61.

**Expert: area problems.** Call the width w, write the length in terms of w, and set width × length equal to the area. Solve the quadratic and reject the negative solution.
