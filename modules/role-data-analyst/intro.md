# Data Analyst scenarios

Cases a data analyst meets: an A/B test to judge, a quarterly KPI report to explain, the rows of a SQL query to summarise and a storage bill to plan. Each case has 2 to 4 parts that use different skills (percentages, probability, SQL conditions, statistics, bytes and compression), and later parts use earlier results.

- **Medium** asks 2 parts with simple numbers, **Hard** 3, **Expert** 4 with rounding stated.
- **Expert+** asks 4 hardest parts: several ideas at once, working backwards, and a judgement part.
- The calculator starts with the numbers in the case as rows. Every rule you need is stated in the question.
