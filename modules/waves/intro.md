# Waves

Practise the core formulas for waves and light. Frequency is in hertz (Hz), wavelength in metres (m), speed in m/s, period in seconds (s), angles in degrees and lens distances in centimetres (cm). Every question states its units and how to round.

| Formula | Meaning |
| --- | --- |
| `v = f × λ` | wave speed = frequency × wavelength |
| `T = 1 / f` | period = 1 ÷ frequency |
| `n = c / v` | refractive index = speed of light in vacuum ÷ speed in the material |
| `n1 sin θ1 = n2 sin θ2` | Snell's law (angles measured from the normal) |
| `sin C = n2 / n1` | critical angle, going from the higher index n1 to the lower n2 (n2 = 1 for air) |
| `1/f = 1/u + 1/v` | thin lens equation |
| `m = h_image / h_object` | magnification as a size ratio, equal to the image distance ÷ object distance (ignoring signs) |
| `P = 1 / f` | lens power in dioptres, with f in metres |

Useful prefixes: 1 kHz = 10³ Hz, 1 MHz = 10⁶ Hz, 1 THz = 10¹² Hz, 1 ms = 10⁻³ s, 1 μs = 10⁻⁶ s, 1 cm = 10⁻² m, 1 mm = 10⁻³ m, 1 nm = 10⁻⁹ m. Light and radio waves travel at 3 × 10⁸ m/s.

**Lens sign convention (real is positive):** the object distance u is positive; a real image has a positive v and a virtual image a negative v; a converging lens has a positive f and a diverging lens a negative f.

| Level | What to expect |
| --- | --- |
| Easy | Whole numbers in the wave equation, simple periods, refractive index from speeds or angles |
| Medium | Unit prefixes (kHz, MHz, ms, μs, nm), oscilloscope traces, refraction angles and critical angles, real images from converging lenses |
| Hard | Decimal values rounded as stated, refraction between two materials, virtual images, diverging lenses, image heights and lens power |

**Tip:** the calculator's trig functions work in degrees, so `asin(sin(40) / 1.5)` gives the refraction angle directly. Rounded answers are accepted within half a unit of the stated precision.
