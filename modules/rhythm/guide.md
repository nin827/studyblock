# Rhythm: how to solve

## General

- Turn every note into beats, with a quarter note as one beat: whole 4, half 2, quarter 1, eighth 0.5, sixteenth 0.25.
- A dot adds half the note's value again: a dotted half is 2 + 1 = 3 beats.
- A bar's length in quarter-note beats is top number × (4 ÷ bottom number): 3/4 is 3, 6/8 is 3, 2/2 is 4.
- Type beats as decimals, like 1.5.

## Note values

1. Find the plain note's beats by halving down from the whole note (4).
2. If it is dotted, add half of that again.
3. To compare two notes, divide one length by the other.

Example: a dotted quarter is 1 + 0.5 = **1.5** beats, the same as three eighth notes.

**Watch out:** a dotted note is one and a half times as long, not twice as long.

## Time signatures

1. Read the bottom number as a note value: 4 = quarter, 8 = eighth, 2 = half.
2. The top number counts how many of those fill a bar.
3. If the top number is 6, 9 or 12, it is compound: divide by 3 to get the main beats.
4. Name it: 2 main beats = duple, 3 = triple, 4 = quadruple.

Example: 6/8 has six eighth notes in two groups of three: **compound duple**.

**Watch out:** 3/4 and 6/8 both hold six eighth notes, but 3/4 has three beats and 6/8 has two.

## Counting bars

1. Find one bar's length in quarter-note beats.
2. Add up the notes: count × beats for each value.
3. Divide the total by the bar length for the number of bars.
4. For "how much is left", subtract what is used from a full bar.

Example: in 3/4, six half notes are 6 × 2 = 12 beats, and 12 ÷ 3 = **4** bars.

**Watch out:** in 6/8 a bar is three quarter-note beats (six eighths), not six beats.

## Tempo

1. One beat lasts 60 ÷ BPM seconds.
2. Total beats = bars × beats per bar.
3. Duration = total beats × 60 ÷ BPM.
4. Working backwards: BPM = total beats ÷ seconds × 60.

Example: 16 bars of 4/4 at 120 BPM is 64 beats × 0.5 s = **32** seconds.

**Watch out:** round only at the very end; use the exact length of one beat when you multiply.
